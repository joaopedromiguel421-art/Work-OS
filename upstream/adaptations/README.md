# Adaptation notes

The manifest records exact pins. These notes record how ideas were transformed and what was deliberately excluded.

- OpenSpec and spec-kit: one simplified spec lifecycle, not two command systems.
- Superpowers: verification and debugging discipline, not its orchestration layer or agent topology.
- Agent Skills and Impeccable: focused engineering/design checklists, not duplicated frontend agents.
- Marketing Skills and Knowledge Work Plugins: consolidated into single domain owners; no provider-specific MCP configuration is copied.
- ECC: safety categories and validation ideas only; no full configuration bundle or duplicate agents.
- Anthropic Skills: structural reference only. Source-available document and brand skills are excluded.

All Work OS Skill bodies and runtime code are original adaptations written for this architecture. No upstream file is automatically synchronized.
