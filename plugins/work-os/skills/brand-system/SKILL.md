# Brand system

## Method

1. Establish audience, category, promise, proof, personality, cultural context, and constraints from verified project evidence.
2. Define a small set of distinctive principles that guide choices rather than a list of generic adjectives.
3. Specify verbal identity: voice dimensions, tone by situation, terminology, claim boundaries, examples, and anti-examples.
4. Specify visual identity at the right fidelity: color roles and contrast, typography roles, spacing/shape/motion principles, imagery direction, and token naming. Separate brand tokens from UI semantic tokens.
5. Demonstrate the system on representative touchpoints with real content and edge cases.
6. Define ownership, approval, accessibility, localization, versioning, and how exceptions are recorded.

## Guardrails

Do not fabricate customer proof, awards, certifications, or performance claims. Do not copy protected logos, trade dress, or a competitor's distinctive expression. Respect existing licensed assets and their usage terms.

## Boundaries

Use `interface-design` for interaction and component behavior, `positioning-and-offer` for the strategic offer, and `copy-and-content` for an individual content artifact. `brand-system` owns reusable expression rules.

## Output

Brand foundation, verbal and visual principles, token/usage rules, touchpoint examples, anti-patterns, accessibility constraints, governance, and evidence gaps.

## Sources and adaptation

Original system built from interface-system concepts in Impeccable and output-governance patterns in Anthropic Knowledge Work Plugins. No Anthropic brand assets or source-available brand Skill content is incorporated.
