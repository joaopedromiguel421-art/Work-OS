# SEO

## Method

1. Define business outcome, audience, market/language, site type, current baseline, and whether the task is technical, page-level, content, or strategic.
2. Research query intent and the actual result landscape with date/location/device caveats. Group by job and page need, not keyword variations alone.
3. Map one primary intent to one canonical page. Identify cannibalization, gaps, internal-link opportunities, and content that should be consolidated or retired.
4. Audit crawl/index controls, canonicalization, redirects, status codes, sitemaps, robots directives, rendering, mobile behavior, page performance, metadata, headings, semantic content, media, internationalization, and structured data where relevant.
5. Prioritize by impact, evidence, effort, dependency, and risk. Fix blocking technical issues before scaling content.
6. Use `copy-and-content` for useful page content and `analytics-measurement` for search/conversion measurement.
7. Put deterministic link, schema, build, accessibility, and performance checks into quality when the project supports them.

## Guardrails

Do not promise rankings, generate doorway pages, hide content, purchase or automate deceptive links, copy competitors, or add structured data that the visible page does not support. Respect search-engine and site terms.

## Output

Scope/baseline, intent map, technical findings with evidence, page/content actions, internal-link map, prioritized backlog, measurement plan, and limits/freshness.
