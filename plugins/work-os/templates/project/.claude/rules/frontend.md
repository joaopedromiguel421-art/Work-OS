# Frontend rules

- Preserve the existing design system and component boundaries before adding primitives.
- Treat keyboard operation, focus, semantics, contrast, responsive behavior, loading, error, empty, and reduced-motion states as acceptance concerns.
- Use real content constraints; avoid placeholder-driven layouts in final work.
- Measure performance before optimizing and keep visual changes covered by the project's available deterministic checks.
