# Skill catalog

Only Skill names/descriptions are always visible; full procedures load on invocation.

| Skill | Authority | Primary activation | Important exclusion |
|---|---|---|---|
| `work` | Named workflow entry | Explicit `/work-os:work` | Never auto-route |
| `project-context` | Context maintenance | Explicit audit/refresh | Not ordinary implementation |
| `evidence-research` | Current attributable evidence | Uncertain/volatile decision fact | Not supplied-data analysis |
| `spec-delivery` | Change contract and slices | Non-trivial delivery | Not tiny obvious edits |
| `architecture-decisions` | Durable technical tradeoff | Cross-boundary/costly reversal | Not routine choices |
| `testing-strategy` | Risk-to-test design | Coverage/regression/flakiness | Not merely running tests |
| `database-changes` | Persistent-data evolution | Schema/data migration | Not read-only analysis |
| `performance-engineering` | Measured performance | Symptom/budget/regression | Not premature optimization |
| `security-engineering` | Threat-driven security | Trust/security exposure | Not generic code review |
| `technical-documentation` | Verified technical docs | Guides/reference/runbooks | Not marketing copy |
| `product-discovery` | User/problem/outcome learning | Material product ambiguity | Not accepted delivery work |
| `interface-design` | UX/interaction/accessibility | Screen/flow behavior | Not brand/campaign strategy |
| `brand-system` | Reusable brand expression | Identity/voice/tokens | Not one asset/screen |
| `market-intelligence` | Market/competitor landscape | External strategic landscape | Not generic lookup |
| `positioning-and-offer` | ICP/value/package | Decide what/to whom/why | Not page/campaign execution |
| `copy-and-content` | Customer-facing words | Copy/content deliverable | Not technical docs/positioning |
| `landing-page` | Integrated conversion page | Create/improve landing page | Not generic app UI |
| `seo` | Organic discoverability | Search intent/technical SEO | Not paid media |
| `cro-experimentation` | Conversion experiment contract | Funnel diagnosis/test | Not unmeasured redesign |
| `campaign-growth` | Coordinated growth campaign | Acquisition/activation/launch | Not auto spend/publish |
| `analytics-measurement` | Metric/event contract | Instrumentation/measurement | Not dataset interpretation |
| `sales` | Account/opportunity work | Prospect/customer/deal | Not auto-send/CRM writes |
| `customer-support` | Support triage/response process | Customer issue/support ops | Not engineering replacement |
| `business-operations` | Repeatable process design | SOP/ownership/capacity | Not platform invention |
| `data-analysis` | Reproducible quantitative analysis | Existing authorized dataset | Not tracking design |

`governance/capabilities.json` is the machine-readable ownership authority. Companion Skills add a distinct lens and never redefine the owner.
